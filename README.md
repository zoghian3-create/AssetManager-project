# سیستم مدیریت دارایی و گارانتی (Asset Manager)

این پروژه یک سیستم جامع برای مدیریت دارایی‌ها (مانند لپ‌تاپ و موبایل) و گارانتی‌های مربوط به آن‌هاست. این مینی‌پروژه با معماری لایه‌بندی شده (Layered Architecture) و با زبان برنامه‌نویسی پایتون پیاده‌سازی شده است.

## ✨ ویژگی‌ها

- مدیریت دارایی‌ها: ثبت کالای جدید، مشاهده لیست کالاها و مدیریت آن‌ها.
- مدیریت گارانتی‌ها: ثبت گارانتی برای هر کالا و مشاهده تاریخ شروع و پایان.
- دیتابیس رابطه‌ای (SQLite): ذخیره‌سازی داده‌ها به صورت پایدار با استفاده از ORM (کتابخانه SQLAlchemy).
- وب‌سرور (FastAPI): دسترسی به داده‌ها از طریق پروتکل HTTP و مسیرهای استاندارد RESTful API.
- سیستم هشدار انقضا: بررسی خودکار گارانتی‌های نزدیک به انقضا با استفاده از کتابخانه jdatetime.
- مدیریت خطا: اعتبارسنجی ورودی‌ها برای جلوگیری از کرش کردن برنامه.

## 🏗️ معماری پروژه

طبق استانداردهای پروتکل پروژه، ساختار به شکل زیر تفکیک شده است:
- models/: شامل کلاس‌های موجودیت‌ها (Asset و Warranty).
- services/: شامل منطق اصلی سیستم (storage_service برای ارتباط با دیتابیس).
- data/: محل ذخیره فایل دیتابیس (asset_manager.db).
- main.py: رابط کاربری متنی (CLI) برای تعامل با سیستم.
- api.py: وب‌سرور FastAPI برای دسترسی از طریق وب.
