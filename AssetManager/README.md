# سیستم مدیریت دارایی و گارانتی (Asset Manager)

این پروژه یک سیستم مدیریت دارایی است که با معماری لایه‌بندی شده (Layered Architecture) پیاده‌سازی شده است.

## ویژگی‌ها
- مدیریت کالاها و گارانتی‌ها
- ذخیره‌سازی داده‌ها در دیتابیس SQLite با استفاده از SQLAlchemy (ORM)
- وب‌سرور FastAPI برای دسترسی از طریق مرورگر
- سیستم هشدار انقضای گارانتی با استفاده از کتابخانه jdatetime
- مدیریت خطا و اعتبارسنجی ورودی‌ها

## نصب و اجرا
1. نصب پیش‌نیازها: pip install -r requirements.txt
2. اجرای برنامه متنی: python main.py
3. اجرای وب‌سرور: uvicorn api:app --reload
